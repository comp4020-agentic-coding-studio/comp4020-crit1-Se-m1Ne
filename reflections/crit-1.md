# Reflections

1. What was the breakthrough that moved the work forward?

The biggest breakthrough in this work was understanding that creating a "forgotten web" style was not as simple as imagining a retro-looking website. The difficult part was explaining the idea clearly and making the result feel like a real website from that era, rather than a modern website with a retro theme. Since English is not my first language, this process was more challenging. In the beginning, I repeated similar but unclear descriptions many times, but the result was still far from what I wanted. The progress became much faster when I started giving more specific instructions, such as adding floating windows, scrolling text, and other details that were common in older websites.

2. What did this work change about who I want to be as a software developer?

This project also changed my understanding of using AI coding assistants. I learned that an AI assistant is mainly a tool for helping write code, not a replacement for my own thinking and design decisions. A developer still needs to have a clear idea, review the results, and provide feedback when the output does not match the goal. During this project, I needed to explain the atmosphere I wanted, compare different versions, and decide which changes actually improved the final website. I also learned that I should not simply follow every suggestion from AI, because some ideas may sound reasonable but move the project away from the original goal.
